# Worddle 🎮

A Wordle-inspired word guessing game built with Flutter and Dart.

## Features
- Interactive word guessing gameplay
- Color-coded feedback for each guess
- On-screen keyboard
- Multiple attempts to find the hidden word

## Technologies
- Flutter
- Dart

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Ahmed-ben-hariz/worddle.git
```

Navigate to the project:

```bash
cd worddle
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
